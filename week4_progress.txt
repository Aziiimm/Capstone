What I implemented this week
============================

1) Sentiment + Hybrid Scoring Module (CPU baseline)
---------------------------------------------------
File added:
- features/sentiment.py

Implemented functions:
- clean_text(text): lowercases review text, removes punctuation, normalizes spaces.
- sentiment_score(text): lexicon-based sentiment score in [-1, 1].
- normalize_sentiment(score): converts sentiment from [-1, 1] to [0, 1].
- add_sentiment_columns(df): adds sentiment_raw and sentiment_norm columns.
- add_hybrid_score(df): computes
    hybrid_score = 0.7 * rating + 0.3 * sentiment_norm
  (weights configurable).
- cold_start_profile_from_texts(texts): builds a cold-start sentiment profile
  from new user text only (mean raw and normalized sentiment).

Why this matters:
- This directly implements Week 4 "Generate sentiment scores".
- It also implements the Phase 2 weighted fusion logic from PLAN.md.
- It provides a practical cold-start foundation for users with no history.


2) CPU Baseline Recommender
---------------------------
File added:
- cpu/recommender.py

Implemented:
- CpuUserKnnRecommender.from_dataframe(df, score_col="rating"):
  builds a user-item matrix on CPU with pandas/numpy.
- cosine user-user similarity computation using numpy.
- recommend_for_user(user_id, top_k, n_neighbors, exclude_seen):
  neighbor-weighted top-K recommendations.
- from_parquet(path): build baseline model directly from cleaned Parquet output.
- batch_recommend(model, user_ids): helper for multi-user recommendations.

Why this matters:
- This fulfills the Week 4 requirement to build a CPU baseline.
- It gives a comparable reference pipeline against the GPU recommender.
